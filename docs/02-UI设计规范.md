# 上岸作战室 ShoreOps —《UI 设计规范：Design System & 页面规格》

- 文档版本：V1.0（与 PRD V1.0 对应）
- 主题基线：浅色主题
- 读者：前端工程师（零歧义还原）、设计、测试验收
- 创建时间：2026-09-18

---

## 1. 设计理念与原则

延续「抢滩登陆作战」隐喻，基调为 **有序、冷静、被托举**：产品是「指挥室」而非「战场」，出现地图、坐标、节点、仪表、补给、战报，不出现枪械/爆炸/骷髅/准星等攻击性图形。军事语言只用于组织信息结构（D-Day、里程碑、阶段、Streak、战报），情绪温度是「参谋在旁、系统托底」。负向场景无红色轰炸、无嘲讽，使用中性灰 + 托底话术 + 下一步动作。

七条原则：①确定感先行（第一屏回答"离 D-Day 几天/今天做什么"）②克制即专业（参照 Apple 留白，装饰 ≤10%，60/30/10 面积比）③层级靠结构不靠堆色 ④状态诚实建议不强制，危险操作二次确认 ⑤被托举而非被催促 ⑥可达性默认开启（颜色+形状双编码、键盘可达、动效可减弱）⑦本地安全感可感知（离线点+隐私文案持续可见）。

## 3. 字体系统

- 字体族：`--font-sans: -apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Source Han Sans SC", sans-serif`
- 数字等宽：`--font-mono-num: "DIN Alternate","Bahnschrift",ui-monospace,"JetBrains Mono",Consolas,monospace`，叠加 `tabular-nums` 防倒计时抖动。
- 字号阶：12/18、13/20、14/22、15/24、16/26、18/28、20/30、24/34、28/38、32/40、倒计时移动 40/48、桌面 56/60。字重仅 400/500/600/700。正文行高 1.55–1.6，标题 1.25–1.3，段落最大行宽 32em。
- 字号三档：标准 1.0 / 较大 1.15 / 最大 1.3（`<html data-fontsize>`）。

## 4. 间距与栅格

- 8px 基准间距：4/8/12/16/20/24/32/40/48/64/80/96。
- 断点：320 / 375–428 / 768 / 1024 / 1280 / 1440 / 1920。
- 栅格：移动 4 列（边距 16）、平板 8 列（24）、桌面 12 列（32，列距 24），内容 max-width 1200。桌面侧栏 240（折叠 64）。触控目标 ≥44px。

---

## 5. 圆角 / 阴影 / 边框 / 层级

- 圆角：4 徽章 / 6 Chip、复选框 / **8 按钮、输入框、Toast** / **12 卡片、模态** / 16 大 Hero；`full` 仅限头像、状态点、进度条，**禁止用于按钮**。
- 阴影：xs `0 1px 2px rgba(18,24,29,.04)`、sm `0 1px 3px rgba(18,24,29,.06)`、md `0 4px 12px rgba(18,24,29,.07)`、lg `0 12px 32px rgba(18,24,29,.10)`；聚焦环 `0 0 0 2px #FBFCFD, 0 0 0 4px rgba(6,182,212,.45)`。卡片默认 1px 边框无阴影，hover 才 shadow-sm。
- 边框：默认 #DDE4E8、强 #C5CFD6、聚焦 #0891B2、危险 #FCA5A5、虚线 #98A6B1（坑位）。
- z-index：base 0 / sticky 100 / sidebar 200 / dropdown 1000 / overlay 2000 / modal 2100 / 呼吸 2150 / toast 3000 / tooltip 3100。

## 6. 图标系统

线性图标默认：24 画布、20 图形区、stroke-width 1.75、round 端点、`fill:none`；激活态切面性版（#0891B2）。SVG 用 currentColor，尺寸 16/20/24/32。

模块图标：指挥台=雷达、作战地图=地图+旗、任务=靶心勾选、漏斗=漏斗、弹药库=层叠文件箱、能量站=电池、复盘室=回转箭头+文档、我的=用户。任务类型：投递=纸飞机、简历=文档、刷题=笔尖、面试=双人气泡、复盘=逆时针箭头、学习=书本、人脉=双人、休整=月亮。

## 7. 核心组件规范

- **按钮**：sm 32 / md 40 / lg 48，圆角 8，图标 16/20。Primary 配色见 2.5；Secondary 白底灰边；Text 透明青字；Danger 实心 #DC2626。加载态旋转环+防重复提交。
- **输入框**：高 40（移动 44），白底、边 #C5CFD6、占位 #697884；focus 边 #0891B2 + 聚焦环；错误边 #EF4444 + 下方红字。Textarea 最小高 96。Select 浮层 radius 12、选项高 40、选中浅青底。
- **复选框/打卡**：20–22，圆角 6；勾选 bg #0891B2 白 check 勾绘 200ms。打卡后卡片 250ms 转灰底、标题灰+删除线；首件完成火焰淡入，可轻震动（try-catch）。
- **开关**：轨道 44×26、滑块 22；开 #0891B2；`role=switch`。
- **Chip**：高 28/32，圆角 6；选中浅青底 #E5FAFD、边 #0891B2、字 #0E7490；预警/危险/信息变体。
- **任务卡**：打卡钮 + 标题（两行截断）+ 元信息（类型 Chip+时长+里程碑+截止）；进行中左缘 3px 青，逾期红字，卡间距 8。
- **申请卡**：字母头像 32 + 公司/职位 + 渠道薪资 + 停留 Chip；拖拽中 shadow-md 不旋转；面试列标"N 轮"。
- **里程碑卡**：节点圆 20 + 标题 + D-x 日期 + 完成率进度条；当前节点外圈静止（不闪烁）。
- **弹药卡**：类型图标盒 36 + 标题摘要 + 标签；题库掌握度 5 点；桌面 3 列。
- **倒计时**：眉题 + 大数字（56/40）+ 天 + 岗位城市 + 高 8 进度条（白色里程碑刻点）。≤7 天琥珀"冲刺期"、≤3 天红色"紧急"（不闪烁）；过期显示顺延按钮；上岸显胜利态。
- **Streak**：面性火焰 #EA580C + 天数；休整券虚线琥珀 Chip；断签显示"历史最长 N 天"不用"断了"。
- **能量电池**：5 枚 14×28，填充能量色，选中深青描边 + 文字标签；支持补记近 3 天。
- **情绪标签**：多选 ≤3，SVG 线描表情（不用 emoji），各色浅底深字。
- **Toast**：深底 #222A31 白字，radius 8，顶部/右上，3s（错误 5s），≤3 条堆叠，aria-live。
- **模态**：遮罩 rgba(18,24,29,.45)+blur(2px)，白卡 radius 12；宽 360/480/640；移动复杂编辑用底部抽屉（≤85vh）。焦点陷阱+Esc+遮罩关闭。
- **确认对话框**：危险图标 + 影响范围 + 必勾确认框；确认按钮动词明确（"永久清空"非"确定"），移动满宽高 48。
- **空状态**：线描插画 96–120 + 标题说明 + 单一主按钮；文案"事实+出路"无压力。
- **导航**：桌面侧栏 240，激活浅青底+左缘 3px 竖条；移动底部 5 Tab（指挥台/任务/漏斗/能量/我的），激活面性青图标。
- **进度条/步骤**：高 6/8，填充 #0891B2，百分比文字同步；里程碑白色刻点。
- **漏斗列**：宽 264、列底 #F5F7F8、列头点+名+数+转化率；拖拽经过列虚线高亮，松手弹记录框（默认勾选生成建议任务）；移动降级 Chips+列表，"更新阶段"作键盘替代。
- **勋章**：圆 56，外圈色环+面性图标 24，未解锁不透明度 .75；解锁顶部卡片提示 4s。
- **Tabs/分段**：下划线式（激活底边 2px 青）、Segmented（灰底白滑块）；移动项高 44。
- **呼吸光圈**：120 同心圆，478 节奏缩放（吸 4/屏 7/呼 8），无频闪；减弱动效改为静止+倒计时弧。

## 8. 关键页面线框布局

- **引导页（≤3 步 ≤1 分钟）**：欢迎（信任行）→ 身份三卡 → 目标设定（D-Day/岗位/城市/作战天数+模板预览），生成态 800–1200ms 骨架文案后进指挥台。
- **指挥台**：倒计时 Hero 卡 → 今日三垒（左 8 列）+ Streak/能量/战备三卡（右 4 列）→ 漏斗 6 列概览。移动：Hero → Streak+能量横排 → 三垒 → 漏斗 2×3，FAB。
- **作战地图**：吸顶工具栏（视图切换/改 D-Day/顺延）+ 阶段色带时间线（节点挂导轨）；桌面甘特图（里程碑条+今日红线+拖拽级联）。
- **任务页**：日期周条 + Tabs（今日/本周/全部）+ 三垒强调容器 + 其他任务分组；右栏战报/Streak/顺延次数。
- **漏斗看板**：工具栏（搜索/新增/视图/转化率/筛选）+ 6 列 264 横滚；右侧滑入 420 详情抽屉（时间线只追加）。
- **弹药库**：左分类树（含待复习）+ 搜索标签 + 3 列卡片；编辑器 Modal（Markdown 编辑/预览+掌握度间隔复习）。
- **能量站**：今日记录卡（电池+情绪+日记）+ 能量曲线（14/30 天+事件点）+ 急救箱 6 工具网格 + 成就预览。
- **复盘室**：Tabs（每日三问/面试复盘/数据洞察）；面试复盘含题目清单+五维评分+动作转任务；数据洞察 4 KPI + 规则诊断。
- **我的**：档案头 + 分组列表（目标管理/提醒/数据管理/外观/关于），容量条与离线指示；清空走确认框。

## 9. 交互与动效

Token：fast 150 / base 200 / slow 250ms；`ease-out: cubic-bezier(.16,1,.3,1)`。仅用于状态反馈、入场定向、空间说明；禁 3D/翻转/摇晃/过冲/环绕/缩放。

- 入场：路由主内容 opacity+translateY(6px) 200ms；hover 卡片 shadow-sm 上浮 1px（`@media(hover:hover)`）；focus-visible 聚焦环；active 即刻变色不缩放。
- 打卡：勾绘 200ms + 卡底 250ms + 火焰淡入；拖拽：起拖 120ms 抬升无旋转，松手 150ms 落位再弹窗；弹窗遮罩淡入 200ms、面板 translateY(8px)；数字变化 150ms 透明交叉不翻滚。
- 减弱动效（系统 reduce 或 data-reduce-motion）：取消位移/缩放/循环，仅保留 ≤120ms 透明过渡；呼吸改静止+弧；骨架屏改纯色，功能不降级。
- 无障碍：键盘路径完整、拖拽有按钮替代、模态焦点陷阱归还、状态双编码、图标按钮 aria-label、手势均可被按钮替代。
