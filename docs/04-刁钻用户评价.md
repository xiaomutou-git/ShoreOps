## 严重程度分级

### 致命 P0（不修不许上线）
1. **数据存续裸奔**：无自动备份、同步对普通用户不可用、清缓存/换设备即全量丢失，引导期未充分告知。
2. **静默吞错文化**：路由守卫裸 catch 曾直接展示错误数据（0天紧急）；全局无上报/降级规范。
3. **功能兑现涉嫌虚假宣传**：以"拖拽看板/甘特图/间隔复习"命名，交付为下拉列表/缺失/无闭环，无"开发中"标注。

### 严重 P1
1. 首日任务量失控（实测 240 分钟+），引导不采集"每日可投入时长"，倒排缺关键输入。
2. 375px 无真机验证；看板横滑/Tab/安全区/触控热区存疑。
3. Pinia 与 IndexedDB 一致性、Quota 超限、多 Tab 冲突、PWA 更新均无兜底。
4. 转化率小样本伪精确；停留预警缺失。
5. CORS 生产白名单缺 fail-fast；零知识密钥/恢复/令牌规则未讲清。
6. 跨模块闭环（申请→复盘→任务→复习）未打通，八大模块成孤岛。

### 一般 P2
里程碑路径过深、地图不动态重排；急救/勋章占位、心情曲线稀疏硬画；弹药 Markdown/粘贴/图片/空状态粗糙；面试复盘模板过重缺轻量入口；D-Day 校验不足、身份差异不可感知。

### 建议 P3
统一军事/棒球/缩写术语；空列表给"创建第一条"引导；勋章规则可视化；设置变更重排规则显性化。

## 上线前必做清单
1. 数据安全网：明示本地风险 + 一键加密导出 + 第3/7/14天强提醒备份 + "一键开通"同步；验收凭备份+口令完整恢复。
2. 漏斗二选一：上真拖拽/横滑，或改名"申请列表"。
3. 引导增加"每日可投入时长"，首日任务 ≤ 声明产能 80%。
4. D-Day 校验：拒过去日期，过近目标二次确认。
5. 375px 真机走查矩阵并留证。
6. 全局错误规范：禁裸 catch，核心组件补空状态。
7. 存储边界：Quota、多 Tab、虚拟滚动、移动端清理警告。
8. 转化率诚实化：样本不足不显示百分比。
9. PWA 更新提示，杜绝卡旧壳。
10. 生产配置断言：CORS 非白名单拒绝启动；写清密钥派生/口令遗忘后果/JWT 存储。
11. 功能对账：未闭环入口挂"实验"标识或下线，做"删骨架测试"。
12. 打通一条跨模块链路：标记已面试→自动复盘待办→一键生成改进任务。

## 三个苛刻要求
1. **零操作数据不朽**：无账号零配置下 RPO=0、RTO<30s 凭口令恢复，服务端零知识。
2. **取消表演型思考**：删除固定800ms动画，基于真实约束（产能/依赖/截止/面试日）求解并滚动重排，MAPE<30%，可解释"为何排这三件"。
3. **心理模块达可审计数字健康标准**：声明非医疗+真实危机转介，情绪数据独立加密可删，提供"战场版/温和版"双皮肤联动替换术语。
