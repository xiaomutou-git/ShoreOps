## 二、逐项发现

### 发现 1：SQL 注入 —— 无（验证通过）
- email 提交 `' OR '1'='1' --`：被 zod 邮箱格式拦截返回 400；
- 合法格式含单引号 `a'b@x.com`：返回 401（邮箱不存在，单引号被当普通字符，证明预编译参数绑定）；
- 全部 SQL 使用 prepare + 参数绑定，无拼接。

### 发现 2：认证绕过 / IDOR —— 无（验证通过）
- 无令牌 → 401；伪造 JWT（aaa.bbb.ccc）→ 401；
- alice 上传后用 bob 令牌 GET vault 返回空 data，按 JWT userId 严格隔离，无 IDOR。

### 发现 3：输入校验 —— 无（验证通过）
非法邮箱、短密码、缺字段、SQL 元字符 → 400；未知路由 404；非法 Content-Type → 400。

### 发现 4：非法请求体导致 500 —— 已修复（中危）
- 缺陷：`{bad json` 触发 express.json 的 SyntaxError，原返回 500；
- 修复：错误中间件识别 body-parser 状态码，非法JSON→400、过大→413、编码错误→415，生产返回通用文案；
- 复测：非法 JSON 已 400，正常登录回归 200。

### 发现 5：安全响应头 —— 符合（helmet）
CSP（default/script-src 'self'、object-src 'none'）、X-Frame-Options SAMEORIGIN、X-Content-Type-Options nosniff、HSTS、Referrer-Policy no-referrer、跨域隔离策略。

### 发现 6：限流 —— 有效（低危加固空间）
全局 300/15min、认证 20/15min，RateLimit-* 正常；代理/分布式场景需按真实 IP + 账户维度增强。

### 发现 7：XSS —— 无
用户输入经 Vue {{ }}/v-text 自动转义；唯一 v-html 是 Icon 静态字典（非用户输入）；无 eval/document.write；异步与 DOM 操作 try-catch。

### 发现 8：敏感信息 / 账号枚举 —— 符合
生产错误隐藏堆栈；密码仅 bcrypt；重复邮箱 409；登录失败统一模糊信息（防枚举）。

## 三、残余风险与加固建议

| # | 项 | 等级 | 建议 |
|---|---|---|---|
| 9 | CORS 开发默认 `*` | 中 | 生产用 CORS_ORIGIN 白名单，仅放行正式域名 |
| 10 | JWT 密钥/生命周期 | 中 | 注入 ≥32 位随机密钥并轮换；缩短 access、引入 refresh 与吊销 |
| 11 | 请求体大小单层限制 | 低 | 网关/反代再叠一层 body 限制 |
| 12 | 限流维度 | 低 | 正确处理 X-Forwarded-For，叠加账户维度锁定 |
| 13 | 安全自动化 | 低 | CI 加入注入/鉴权/安全头回归与依赖 SCA 扫描 |
| 14 | 认证形态预案 | 信息 | 若改用 Cookie 须加 CSRF Token + SameSite |

## 四、复测结论
- 非法 JSON → 400（原 500 已修复）；超大/编码错误 → 413/415；
- 正常登录 → 200（无回归）；无令牌/伪造/跨用户/注入等原有控制全部保持有效。

## 五、上线阻断项
1. 生产配置 CORS 白名单、移除 `*`；
2. 生产注入 ≥32 位随机 JWT_SECRET 并纳入密钥管理。

**总体结论：注入、认证、隔离、XSS、响应头与零知识架构控制有效；唯一真实缺陷已修复；落实两项生产配置阻断与纵深加固后可安全上线。**
